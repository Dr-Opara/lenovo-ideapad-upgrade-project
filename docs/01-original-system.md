# 01 - Original System

## Device

Lenovo IdeaPad Gaming 3 15IHU6  
MTM: 82K100L5US

## Factory / pre-upgrade configuration

- Intel Core i5-11300H
- NVIDIA GeForce GTX 1650 4 GB
- 8 GB installed RAM
- Approximately 512 GB SSD
- Windows 11

The project began after the system drive had become relatively full and the machine was also limited by 8 GB of memory during multitasking and development workloads.

## Upgrade objective

The objective is to improve day-to-day responsiveness and available storage without unnecessarily replacing the existing Windows installation.
