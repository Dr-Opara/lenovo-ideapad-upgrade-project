# 07 - Lessons Learned

This file will be updated as the project progresses.

Initial notes:

- Verify exact laptop model before purchasing upgrade parts.
- Match RAM form factor and generation, not just capacity.
- A matched 2 x 16 GB kit is preferable to mixed-capacity modules when targeting 32 GB.
- Removing RAM does not erase files; files are stored on the SSD.
- Removing an SSD does not erase it, but its files become unavailable until the drive is reconnected.
- Disconnecting battery power before internal hardware work is an important precaution.
- Confirm the exact M.2 slot before installing an NVMe drive.
