# 03 - Disassembly

## Steps completed

1. Shut down Windows completely.
2. Unplugged external power.
3. Removed the bottom cover.
4. Identified the motherboard, RAM area, storage area, cooling system, and internal battery.
5. Removed the internal battery before installing new components.

Removing battery power before handling RAM or SSD hardware reduces the chance of accidental shorts while working inside the laptop.

## Current milestone

The laptop is open and the battery is physically removed. The next steps are the RAM installation followed by SSD installation.
