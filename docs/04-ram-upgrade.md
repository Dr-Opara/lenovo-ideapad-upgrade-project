# 04 - RAM Upgrade

## Existing configuration

The laptop originally had 8 GB installed.

## New configuration

The upgrade kit contains two Timetec 16 GB DDR4-3200 SODIMM modules for a total of 32 GB.

## Installation procedure

1. Confirm the internal battery is disconnected or removed.
2. Release the retaining clips holding the existing RAM module.
3. Remove the original 8 GB module.
4. Insert the first 16 GB module at an angle, aligning the notch.
5. Press the module downward until both retaining clips lock.
6. Install the second 16 GB module into the remaining slot.
7. Confirm both modules are fully seated.

## Expected result

- Slot 1: 16 GB
- Slot 2: 16 GB
- Total: 32 GB
- Expected memory speed: DDR4-3200 / 3200 MT/s, subject to system firmware configuration

## Post-install verification

After reassembly and boot:

Windows Task Manager -> Performance -> Memory

Verify that Windows detects approximately 32 GB installed.
