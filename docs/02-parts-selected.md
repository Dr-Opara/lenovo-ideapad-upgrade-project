# 02 - Parts Selected

## RAM

Timetec Premium 32 GB kit:

- 2 x 16 GB
- DDR4-3200
- PC4-25600
- 260-pin SODIMM
- 1.2 V
- CL22
- Non-ECC
- Unbuffered

This kit replaces the original 8 GB memory module and fills both available SODIMM slots.

## SSD

A 1 TB M.2 2280 NVMe SSD was selected for additional internal storage.

The original ~512 GB SSD will remain installed so the existing Windows installation, applications, and files are preserved.

## Upgrade target

After completion:

- RAM: 32 GB total
- Existing SSD: ~512 GB
- Added SSD: 1 TB
- Total raw storage: approximately 1.5 TB
